# ♪ 悠扬五线谱识谱游戏

帮助孩子建立谱面位置、琴键位置和实际音高之间的对应关系。

## 游戏内容

- 认识音符、音程与和弦，配合鼓励和朗读卡片。
- 找琴键时播放对应音高，正确音符在谱面显示或高亮。
- 和弦练习第二步只需找齐三个指定白键，顺序不限。
- 和弦第一步答对后可重复点按听和弦，再通过按钮进入第二步。
- 标题旁可切换声音开关；小屏幕键盘支持左右滑动，超出屏幕时显示滑动提示。
- 按当前屏幕高度分配练习区；手机关卡选择收成一行，短窗口中朗读卡放在右侧。朗读字号保持不变。
- 提示在题目旁；设置、学习记录和和弦音程说明按需打开，可点击关闭或按 Escape 返回。
- 完成后收起已答完的选项，琴键仍保留，可继续听音。和弦第一步保留正确答案，支持重复点击。
- 使用动态视口高度适应手机浏览器工具栏；极小窗口或放大字体时允许自然滚动，避免截断内容。

## 运行与发布

游戏是完整的静态页面，不需要安装依赖或启动后端。打开 `index.html` 即可运行。

GitHub Pages 发布目录：`main` 分支的根目录。`.nojekyll` 用于直接发布静态文件。

## 验证

使用 Node.js 运行：

```sh
node tests/audit-fixes.cjs
```

测试覆盖题目判定、任意顺序找琴键、音高映射、音频恢复与取消、重复点击、声音开关，以及紧凑关卡选择、展开/关闭说明、避免自动移动页面及键盘溢出提示的状态逻辑。

这些测试使用 DOM 模拟；真实浏览器的排版以及手机触摸滑动、可听音效仍未验证。代码检查不等于已在全部手机上实现一屏呈现。
